## RIDM 20 Application

A source-code recall item: the limiting value of a scaled quantity as a
parameter grows without bound, per a specific game's code. Closed book, no
derivation path exists; the run was a referent prediction over what the code
contains. The base value recall was correct. The design-coherence read was
also correct: the item names a specific entity, so the answer had to be
entity-specific, which eliminated the generic data-type-bound reading. Two
mechanism classes were enumerated for the limit: a convergent per-player
series (committed, with its truncation variant named) and the integer
storage bound (demoted on the entity-specificity argument).

The key holds a third mechanism: the code's growth formula diverges, and the
source imposes an explicit clamp constant on the multiplier. The answer is
the base value times that clamp. The committed mechanism class was wrong,
and the true class was never in the candidate set.

## Framework Observations

- Coverage gap at the mechanism-class level: for a maximum-per-source item,
  the candidate mechanisms are at least a convergent formula, a data-type
  bound, and an explicit clamp constant. The clamp is arguably the most
  likely authored referent, because it is a quotable, intentional line of
  code, and the stem's "according to the source code" pays off maximally on
  exactly such a line. The deletion test was available: the committed
  convergent reading survives deletion of that phrase almost unchanged,
  which marked the phrase as unconsumed.
- The banding discipline worked as written: unverified numeric recall at the
  decisive link committed at the low band by rule, and the loss lands in the
  band where the audit expects losses. The category's lifetime record stays
  consistent with that pricing.
- The entity-specificity argument (a named subject implies a
  subject-specific answer) did real work, killing the storage-bound rival,
  and survives this miss intact: the keyed answer is indeed
  entity-specific.

## Lessons

Candidate for the sprint file: on recall items asking for a maximum, cap, or
limit "per the source," enumerate the mechanism class before the value:
convergent formula, data-type bound, explicit clamp. An explicit clamp
constant is the modal authored referent for quotable-maximum items, and a
stem phrase that the committed reading would survive deleting is an
unconsumed flag pointing at the more literal mechanism.
