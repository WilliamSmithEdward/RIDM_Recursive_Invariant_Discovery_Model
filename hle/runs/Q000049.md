## Lessons

1. On multi-part formal items, classify each part as axiom-trivial,
   hypothesis-dependent, or refutable before proving anything; the classification
   localizes effort and exposes which single links carry the commitment's band.
2. When a formal setting is fully self-contained, the axioms outrank any recognized
   domain costume: intuitions imported from the costume domain are narrative-tier, and
   this cuts both ways, since here they would have added false positives.
