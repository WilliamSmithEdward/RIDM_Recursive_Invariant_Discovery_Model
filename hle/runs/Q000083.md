## RIDM 19 Application

A coupled second-order system with explicit time dependence, a terminal
rest condition at a parameter time, and an integral over that parameter of
the reciprocal initial-coordinate sum. The reduction was found immediately:
the combination t q' - q turns the system into a first-order linear system
u' = -t A u for a small integer matrix, so the initial state is a matrix
exponential of the terminal state in the variable t^2/2. The matrix's
characteristic polynomial collapses (one nonzero eigenvalue, a nilpotent
block), Cayley-Hamilton gives a three-term closed form for the
exponential, and the coordinate sum reduces to a two-term exponential
expression whose reciprocal integrates to a polylogarithm value at a
rational argument.

Validation ran three convergent routes before commitment: the closed-form
exponential identity checked against a numeric matrix exponential at three
parameter values, a backward Runge-Kutta integration of the transformed
system from the terminal condition reproducing the coordinate-sum formula,
and the numeric integral agreeing with the polylog closed form to thirty
digits. The key matches the committed closed form exactly, and its
per-component initial positions sum to the same expression.
