## Lessons

1. When a recalled classical constant is attached to one of several closely related objects
   (differing by a center, a quotient, or a sign), derive the discriminating factor rather
   than trusting which object the memory names.
2. Rational Euler characteristic is a strong convergent route for index computations: it
   depends only on coarse invariants (rank, torsion-freeness), not on the explicit
   generators, so it is nearly independent of the conjugation route.
