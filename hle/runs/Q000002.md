## RIDM Application

Fully derivable task: no recalled facts were load-bearing. The material structure was a
two-sided argument, an impossibility bound plus an explicit construction achieving it. The
attempt treated the pair as the closed-world equivalent of validation: neither half alone
would have justified high confidence.

Two framework-relevant events occurred during the attempt:

- A superficial counting argument gave an attractive but non-tight bound. The materially
  binding constraint was a structural one (monotone accumulation of earlier choices) that the
  superficial argument ignored. Ranking constraints by which one actually binds, rather than
  by which one is easiest to apply, located the true answer.
- A quick continuum estimate and a rigorous potential-function derivation disagreed on the
  constant. The disagreement was resolved by preferring the more direct derivation, exactly
  the discipline Section 17 prescribes for conflicting external evidence, applied here to two
  internal reasoning routes.

After the reveal, the official bound used a different argument from mine; both reached the
same constant, which retroactively confirms the route-convergence signal.

## Framework Observations

- Section 17 frames evidence conflict as an external-source phenomenon. Conflicts between an
  agent's own reasoning routes behave identically and need the same rules: no averaging,
  prefer directness, record what would resolve the conflict.
- Benchmark-grade questions are adversarially calibrated: the most available invariant is
  often placed to be almost right. A deliberate pass asking which constraint is load-bearing,
  and whether the obvious bound is designed to be non-tight, changed the outcome here.
- A bound plus an achieving witness is the strongest closed-world validation available for
  extremal claims; this strengthens the case for the closed-world validation rung (L1).

## Lessons

1. Extend the conflicting-evidence rules to internal route conflicts explicitly.
2. Add an adversarial-calibration check to interpretation: identify the constraint the
   problem designer expects to be under-weighted; test whether the obvious bound is tight.
3. For extremal claims, closed-world verification means bound plus witness, two halves from
   independent arguments where possible (reinforces L1).
