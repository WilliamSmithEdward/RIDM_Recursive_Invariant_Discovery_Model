## RIDM 27 Application

A menu asking which four lexical features a specific annotation
study found most predictive of word complexity for advanced
non-native and native speakers. The item was typed retold in my own
words: a paraphrase of a published result, with the key holding the
source's finding. The source was not identified. The ranking then
used the wrong instrument for that rigor class: the option that sat
at the center of the distractor cloud, sharing the most features
with the others and coinciding with the textbook predictor set, was
committed as the seed. The key is the option with the two features
no other option shares. The source is a 2021 annotation study, and
its feature set is the outlier.

## Framework Observations

- Rigor class selects the tool, and the selection is made before the
  ranking effect is seen. Seed centrality predicts the key on
  generated items, where distractors are perturbations of the
  generator's own output. On a retold expert item the author builds
  distractors by perturbing away from the key, so the shared features
  mark the harvested cluster and the semantically distinct outlier is
  presumptively author-voiced. The framework already states both
  rules; the run applied the generated-item rule to an item it had
  typed retold.
- The textbook feature set was the consensus magnet. On an
  expert-authored menu the pool-filter check says the key sits away
  from the reference population's modal answer, and it was not run
  at all here, the third under-application of that check this sprint.
- Coverage held (every option was ranked) and the band was capped at
  medium for an unidentified source, so the loss was priced, but the
  ranking inverted the framework's own rules.

## Lessons

- Type the item's rigor class first, then choose the menu tool it
  licenses: centrality for generated menus, harvested-cluster
  outlier for retold and expert menus. Applying the generated-item
  rule to a retold item is a category error that the gate's
  standing-rules check should catch.
- The pool-filter check runs on every expert menu as a required
  step, not when convenient; a textbook-consensus option is the
  magnet it predicts against.
