## RIDM 18 Application

A small closed-form exercise: differentiate a discounted value objective with
respect to two directly-parameterized action probabilities at one state. The
item classified well-posed, so the derivation was run to completion and
committed. Two routes sharing almost no machinery agreed exactly: the named
theorem for this gradient (discounted state-visitation weight times action
value) and direct symbolic differentiation of the closed-form value function,
with a finite-difference numeric check and a ratio consistency check on the
two components. Every given was consumed and no alarms were open.

The key computed a different object: it expanded one Bellman step and
differentiated while holding the continuation values constant, producing the
first-step semi-gradient, the initial-distribution weight times the action
value, instead of the visitation weight times the action value. The defect is
checkable two ways. Internally, the key's own rationale solves the coupled
fixed-point system because the value function depends on the policy, then
treats those same symbols as policy-independent during differentiation of the
same expression. Externally, both key components reproduce exactly as the
derived gradient times the ratio of initial weight to visitation weight, the
signature of differentiating only the explicit first-step occurrence. Graded
strictly: incorrect.

## Framework Observations

- Sequencing discipline held and was still graded down. The rigorous route
  succeeded, so no author-error model was licensed, and committing the true
  derivative was the process-correct move under derivation-first sequencing.
  Predicting the semi-gradient key would have required exactly the
  overcorrection RIDM 14's sprint punished.
- Oracle-defect differencing worked as designed. The redundant
  differently-grouped computation done before commitment made the post-reveal
  defect proof immediate: an exact multiplicative offset shared by both
  components, plus an internal inconsistency in the key's own derivation.
- The banding residual is real. The correct route here passes a canonical
  trap with a name, the naive shortcut that a well-known theorem exists to
  correct, and that shortcut also yields a clean closed form. That
  configuration is an observable, pre-reveal predictor of elevated
  defective-key risk on an otherwise well-posed item, and the compound
  two-component answer already carried a stated allowance that was not
  applied. The high band was honest about the mathematics and miscalibrated
  about the referent.

## Lessons

1. On a well-posed item whose correct route passes a named canonical error
   mode, one a standard theorem exists to correct, and the erroneous shortcut
   also produces a clean closed form, the shortcut's output is a live
   defective-key candidate: compute it alongside the true result before
   reveal, and apply the compound-answer allowance to the band rather than
   committing at the derivation's full strength.
