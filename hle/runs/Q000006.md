# Run Q000006

- Date: 2026-08-30
- Category: Other (art history)
- Answer type: exact match
- Image: none
- Result: incorrect
- Stated confidence before reveal: low, about 35 to 40 percent, with three named alternates

## RIDM Application

An irreducible-recall task: no derivation path exists for a who-said-this question, so the
whole attempt is abduction over recalled candidate profiles. The attempt correctly recognized
the regime, typed every claim as weak inference, ranked candidates against the clues, stated
low confidence, and named alternates.

The committed answer was wrong, and so were all named alternates: the true answer was not in
the candidate set at all. Post-reveal inspection showed the answer was well within the
attempt's background knowledge, including the specific signature work that one clue pointed
at almost uniquely. It was never retrieved because the memory probes were shaped by an early
unconscious narrowing: two clue words were read as one category's vocabulary, and every probe
thereafter searched only that category.

## Framework Observations

- In recall regimes the binding constraint is candidate-set generation, not ranking. Section
  20 bounds interpretation generation but never addresses answer-candidate coverage; the
  same coverage discipline applies.
- Consistency-scoring favors availability: every clue was checked for compatibility with the
  candidates already on the list. The discriminative move is the reverse: for each clue, ask
  what it uniquely selects, independently of the current list, and let those probes widen the
  set. One clue here was a near-unique selector for the true answer.
- Retrieval is query-shaped. Probing memory once per discriminative clue, rather than once
  for the gestalt, would have surfaced the answer immediately.
- Calibration tracking across runs is now producing signal: high-confidence commitments are
  2 for 2, low-confidence 0 for 1 (as expected), but medium-confidence commitments are 0 for
  3. The middle band is inflated, and the specification has no mechanism that would notice.

## Lessons

1. Extend coverage discipline to answer-candidate sets: before ranking, widen the set with
   one retrieval probe per discriminative clue, asking what each clue uniquely selects.
2. Track confidence-band calibration against outcomes across tasks; recalibrate bands that
   drift. Stopping calibration exists as a metric in Section 55, but per-band confidence
   calibration does not.
