difference is unobtainable, with an option asserting that several are. The attempt

## Framework Observations

- The decisive link was a silently imported rule convention. The stem named only the
  game family, so some ruleset had to be assumed, but the convention choice was never
  represented as a candidate reading, priced, or stress-tested, although the framework
  already treats convention spaces as enumerable and this item's rules were exactly
  such a space.
- The purposeful-conditions coherence signal was observed and dismissed: under the
  parity reading the entire constructed position was decorative, the anomaly was
  noticed in so many words, and the attempt proceeded anyway, the undischargeable-alarm
  failure by the book. A reading that renders an item's elaborate constructed
  specifics pointless should be demoted for the same reason as a reading that
  trivializes a stated requirement; an author who builds a detailed position built it
  to matter.
- This is convention defaulting generalized from discretization conventions to rule
  variants, and it is the inverse of the previous sprint's pattern: here the canonical
  convention was the wrong one, and the tiebreaker that should have caught it was not
  canonicality but load-bearingness of the stem's own construction.

## Lessons

1. On game items with unstated rules, the rule-variant space is a convention space:
   enumerate the ending and capture variants as candidate readings and rank them by
   which makes the constructed position load-bearing, before any invariant argument is
   allowed to trivialize the item.
2. An elaborate constructed position is a stated requirement in the coherence sense:
   a reading under which it is decorative fails the same test as one that trivializes
   an explicit constraint, and noticing that anomaly obligates re-ranking, not a note.
