## RIDM 19 Application

A tandem-MS item: which recorded fragment masses evidence an acyl
modification on a peptide's lysine. The measurement layer went perfectly:
every one of the six recorded values was assigned programmatically, a
constant author-side arithmetic offset was detected across the whole set
(consistent at both charge states), and exactly two values were shown to
carry the modified residue, one singly and one doubly charged. The key's
own rationale makes the same two assignments.

The loss came at the option-semantics layer. The two-value set appears in
no option: some options mix a modification-bearing value with unmodified
fragments, one names only the doubly-charged carrier, and a none-of-the-
above option exists. The specification's standing rule, a scope-humble
true option dominates none-of-the-above under a choose-the-correct-answer
criterion, pointed at the incomplete-but-all-true option. The attempt
explicitly narrowed that rule's scope with an imported premise that
options are candidate complete answer sets, and committed none-of-the-
above. The key holds the all-true incomplete option, exactly as the
unnarrowed rule predicts.

## Framework Observations

- Sophistication capture against the reasoner's own spec: the canonical
  rule was constructed, named, and then defeated by an interpretive
  meta-frame (set-completeness) that the stem never licensed. Repairing a
  standing rule's scope to fit a cleverer reading is charitable text
  repair applied to one's own framework.
- The selection structure the key implies is cleaner than either frame:
  rank options by containing no false element first, then by coverage;
  none-of-the-above loses to any no-false-element option. The committed
  frame would need explicit stem language (select all, complete set) to
  apply.
- The instrumentation discipline held (all six values assigned, offset
  model verified at two charge states) and localized the loss precisely:
  referent prediction at the menu-semantics layer, not measurement.

## Lessons

1. On which-of-the-following menus without select-all language, an option
   whose every element is true dominates none-of-the-above even when it is
   incomplete; completeness is an imported premise requiring stem license.
   A standing canonical rule may not be scope-narrowed at commitment time
   by a meta-frame the stem never stated.
