## RIDM 23 Application

A two-filter recall menu: a gene-location criterion and a
physiological-magnitude criterion, with the menu built so the
strongest magnitude magnets fail the location or monogenicity filter
and several genuine location matches fail the magnitude filter. Each
option was typed against both filters independently: three
metabolic-rate magnets excluded as non-monogenic or wrong
chromosome, four true location matches excluded on magnitude, one
option passing both. The autoimmune magnet was the designed trap,
carrying a chromosome-2 susceptibility locus that tempts a partial
credit read of the location filter.

## Framework Observations

- On conjunctive-criterion menus, evaluating every option against
  every filter separately, rather than shortlisting by the more
  vivid criterion first, is what exposes the designed trap: the
  most famous answer for the vivid criterion fails the quiet one.
- Whole-menu coherence held: one rule set assigned every option a
  role (magnet failing filter one, match failing filter two, joint
  pass), which lifted a recall-backed commitment to medium under
  the banding rules, and the audit rewarded it.

## Lessons

No new failure lesson. Win pattern: on conjunctive filters, type
all options against the quiet filter before ranking on the vivid
one; the key is usually the only joint pass, and the vivid-filter
champion is the plant.
