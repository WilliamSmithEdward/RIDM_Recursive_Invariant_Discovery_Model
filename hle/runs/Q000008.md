## RIDM Application

A recall-regime question about the differences between two archival versions of a silent
film. The attempt eliminated impossible options using plot facts, then chose by
narrative-level abduction: restorations recover source fidelity, so the restored element
should be the missing canonical event.

The revealed answer was instead a film-philology fact: the restored material was the first
part of the very shot the question described, extending the same moment rather than adding a
new event. The question's own wording carried the discriminative evidence: one adjective
marked the known version's shot as short, and the question described that shot's content in
unusual detail. The correct option was the unique continuation of that described moment.

## Framework Observations

- The task text itself is an evidence source, separate from domain memory. Oddly specific
  descriptions, emphasized adjectives, and asymmetries of detail in the question are
  micro-evidence, and the unique-selection probe (L14) should run over them first, before
  reaching into background knowledge. Narrative-plausibility abduction outranked
  question-internal textual evidence here, and lost.
- Calibration data hardened: the medium confidence band is now 0 for 4 across runs, while
  the high band is 3 for 3 and the low band 0 for 1. Medium confidence in recall regimes is
  systematically inflated and should be capped near the option-count prior when recall is
  weak. This strengthens L15.

## Lessons

1. Mine the task text for discriminative micro-features (emphasized qualifiers, oddly
   specific detail, described asymmetries) and run unique-selection probes over them before
   consulting domain memory. The describing words often co-vary with the answer.
