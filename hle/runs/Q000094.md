## RIDM 20 Application

A reranking item built as a double minimal pair: two questions differing
only in a negation, two documents differing only in one temporal phrase.
The designed-detail discipline resolved it directly: the single engineered
difference between the documents (a life-stage phrase) pays off only under
the assignment that pairs each question's polarity with the document whose
timing entails it. The equal-ranking option was identified as the magnet
for readers who miss the swap, and the inverted assignments leave the
engineered difference decorative.

The key's rationale confirms the item was constructed to catch models that
rank one document above the other for both questions or fail to process
the negation; the intended answer is exactly the polarity-respecting
assignment.

## Framework Observations

- Minimal-pair construction is the cleanest case for the
  designed-details-select rule: when the stimulus is duplicated up to one
  edit, the edit is the entire contract, and the committed reading must
  consume it. The deletion test doubles as the tie-breaker against the
  equally-ranked option, which is exactly what the item's author planted.
- Entailment did the object-level work: a change at puberty entails no
  change during babyhood, which is what makes the negated question rank
  the later-timing document first rather than treating both documents as
  merely on-topic.

## Lessons

No new lesson; the run confirms the existing designed-detail and
hint-consumption disciplines on a purpose-built contrast item.
