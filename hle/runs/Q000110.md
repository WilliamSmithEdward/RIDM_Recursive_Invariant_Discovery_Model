## RIDM 21 Application

A minimal-moves puzzle over a five-peg, nine-disk variant with a scattered
start. The state space is small (each disk's peg determines the whole
configuration, under two million states), so the direct instrument was an
exhaustive breadth-first search rather than a heuristic argument. The
solver was validated on the classic three-peg anchor before use, the
optimal move count was extracted, and the witness path was reconstructed
and legality-checked move by move against the stem's rules. The key's own
optimal trace uses a different path with the same count, as expected for
a problem with many optima.

## Framework Observations

- Instrument discipline as specified: anchor-validate the solver on a case
  with an independently known outcome, then trust it on the unknown case;
  pair the extremal claim with a verified witness (bound plus witness,
  Section 40).
- Recognizing that the state space was exhaustible converted an
  optimization item from inference to derivation. The check for whether
  brute force is feasible belongs before any cleverness.

## Lessons

No new failure lesson. Win pattern: size the state space first; when it is
exhaustible, search it completely, validate the searcher on an anchor, and
verify the witness against the stem's own rules.
