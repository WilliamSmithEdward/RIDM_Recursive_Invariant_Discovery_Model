## RIDM 27 Application

fewest cells so that no five consecutive occupied cells remain on
any row, column, or diagonal. The item was typed well-posed and
finite, so the rigorous route was exact computation: a binary
integer program with one constraint per five-cell segment in the
four line directions, solved to proven optimality. The optimal
witness was re-verified against every segment by independent code,
and a second query with the occupancy forced one higher was proved
infeasible, giving two solver certificates for the bound.

The key's rationale is a human proof: a cyclic five-coloring gives
the construction and a case analysis on forced removals gives the
lower bound. Both agree with the computed optimum.
