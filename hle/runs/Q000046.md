## Framework Observations

- Rigor misclassification in the reverse direction from earlier sprints: casual costume
  concealed a retold experimental core. The retold class never engaged, so the rule
  that a retold item's key holds the source's published value never fired, although the
  source was partially recalled.
- The stem hint was consumed decoratively, for order-of-magnitude only, when it named
  the causal mechanism whose direction decides the answer. A hint of the form
  "consider X in the analysis" is a flagged observable: the analysis must give X a
  causal role with a direction, and an attempt whose answer would be unchanged with X
  deleted has not consumed the hint.
- The derived pair matched no menu option within its own error bars. On an authored
  menu the intended computation's result is normally present exactly; a derivation
  matching nothing is evidence against the model choice, not grounds for choosing the
  closest option. The alarm was noticed and priced instead of discharged, the exact
  failure Section 24 names.
- In empirically governed domains, an idealized first-principles estimate is itself an
  inference whose validity is an assumed claim; it does not carry derivation-tier
  precedence over a recalled experimental result from a matching source.

## Lessons

1. An anti-model trap in an empirical domain is usually a retold recent experiment
   whose result inverts the textbook estimate, and a mechanism-naming hint is the
   standard tell; when a stem hints at a mechanism, ask which answer direction the
   mechanism favors before computing magnitudes.
2. Treat menu mismatch as model refutation: if the derived value is not on the menu
   within its uncertainty, reopen model identification and search for a retold source
   instead of committing to the nearest option.
3. Derivation-tier precedence belongs only to derivations whose governing model is
   itself supported; in turbulence-adjacent and biological domains, idealized closed
   forms rank as inference, not derivation, against source-matched experimental recall.
